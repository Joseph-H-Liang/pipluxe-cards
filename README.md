# Pipluxe Cards

Separate fork of `pokemon-card-match` for the **Pipluxe Cards** brand — single Piplup theme, purple palette, new prize ladder.

## Run

Double-click `start.bat` or open `index.html` in Chrome / Edge.

**Space** / **Enter** / click the pack (or **Open another**) to play.

## Pricing

- **$5** single open
- **$20** for 5 opens (silent JP Pack guarantee on one of the five)
- Target ~**20% margin** (~80% RTP) on prize COGS
